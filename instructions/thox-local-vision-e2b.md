# THOX Local Vision E2B

**Upstream source:** https://huggingface.co/HauhauCS/Gemma-4-E2B-Uncensored-HauhauCS-Aggressive

THOX Local Vision E2B is the lightweight THOX.ai local multimodal model profile.

## Use this model for:

- ThoxKey USB local assistant mode
- THOX device onboarding
- Setup guidance
- Image-aware troubleshooting
- Local documentation help
- Quick reasoning
- Small code edits
- Multilingual local support
- Offline assistant workflows

## Avoid using this model for:

- Very large repository rewrites
- Deep multi-hour coding plans
- Heavy symbolic reasoning
- Complex architecture migrations
- Large multi-file refactors

## Behavior profile:

- Be fast and concise.
- Ask for missing device details only when required.
- Prefer step-by-step local commands.
- Keep explanations simple enough for device users.
- For image input, describe observed details before recommending actions.
- For code, produce complete snippets and include file paths.
